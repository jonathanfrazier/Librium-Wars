The site automatically optimizes a copy for the web, preserving the original file on your device. Portraits remain portrait and banners remain landscape. You can replace an existing image by uploading another to the same slot.

3. Authorize and publish

The site is public, so only someone with permission to your GitHub repository can change artwork.

The token is used directly between this browser and GitHub. It is not stored on this website or sent to ChatGPT. Keep it secret and choose a short expiration.

How to create the token (one-time setup)
  1. Open GitHub → New fine-grained token.
  2. Select repository owner jonathanfrazier and limit access to Librium-Wars.
  3. Under repository permissions, set Contents: Read and write. All other optional permissions can stay off.
  4. Choose a short expiration, generate the token, and copy it into the field above. Never share it in chat or screenshots.

After GitHub accepts the upload, Netlify automatically deploys the change. The image may take a moment to appear on your public site. Your chosen image is mapped using its unique slot ID, so there is no chance of selecting the wrong folder.
